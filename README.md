# Worst Superpower

A one-line entry for the make.fun "Worst Superpower" contest: superhuman
dodging reflexes that always kick in exactly one second after whatever was
thrown has already hit — a power that works perfectly, just always too late.

## Run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating `/output` if
needed). Python standard library only; no dependencies.
